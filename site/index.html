Cull, develop and export straight from the card

PhotoCull is a desktop app for photographers. Back up the card, pick your keepers from RAW and JPEG previews, develop the RAWs, hand them to your editor and export finished images.

Download PhotoCull View the source

Windows and macOS on Apple Silicon · Free and open source, MIT

One pass from card to finished files

  1. Cull

    Open the card and go through it with the keyboard. P picks, X rejects, 0–5 rates. Bursts stack, and the sharpest frame is marked.

  2. Develop

    Adjust RAWs with a live preview and an interactive histogram. Save a look as a recipe and paste it onto other photos.

  3. Edit in…

    Send 16-bit TIFFs to the editor you configure. PhotoCull sees when you save and shows the result everywhere.

  4. Export

    JPEG, JPEG XL, TIFF, PNG, AVIF or WebP, with sizing, sharpening, colour space, metadata and naming presets.

No catalog, no import step and no account. Decisions are saved as you make them, and as XMP sidecars beside the photos when you want them to travel.

What it does

Verified card backup

Back up card… copies every file on the card and checks each copy with SHA-256. It tells you when the card is safe to format. Running it again verifies and skips identical copies.

Contact sheet

Every thumbnail shows its flag, stars, colour label and burst count. Drag or Shift-click to select several photos and decide for all of them at once; one undo takes it back.

Focus points and bursts

Press A to see where the camera focused, and Shift+A to open that spot at 100%. It reads the focus data Sony, Nikon, Canon, Fujifilm, OM System and Panasonic write.

Frames shot in quick succession stack together. Keep sharpest picks the frame with the most detail and rejects the rest, in one step you can undo.

Compare

Put two to four photos side by side with zoom and pan linked. Pick, reject and rate each pane from the keyboard, and swap in the next candidate with the arrow keys.

RAW Develop

White balance, light, tone curve, lens corrections and detail, with a live preview. Drag the histogram to move a tonal zone, press J for clipping and Shift+\ for a before and after split.

Recipes keep a look; a flat base for film emulation is included.

Edit in your editor

Add any application as an external editor and choose the format, bit depth, colour space and arguments. PhotoCull develops the RAW, opens the file and notices when you save it back. A Dehancer preset is built in.

Export finished images

JPEG, JPEG XL, TIFF, PNG, AVIF and WebP. Resize, sharpen for screen or print, pick the colour space and what metadata to keep, and save it all as a preset.

Export uses your saved edit when there is one and develops the RAW when there is not. Source files are never overwritten.

Keyboard first

Every action is in the command palette, and the frequent ones have shortcuts you can change in Settings. Type > in the palette to jump to a photo by name. On a Mac, Ctrl is ⌘.

Your originals stay as they are

  • Sources are read onlyCulling, Develop, hand-offs and export never change the bytes of a source photo or of anything on the card.
  • XMP sidecarsRatings, labels and decisions go in standard XMP beside the photos, so other apps can read them. Cards get none unless you ask.
  • A Trash of its ownDel moves a photo to PhotoCull's Trash and Ctrl+Z brings it back. Files are deleted only when you empty the Trash or confirm a permanent delete.
  • Works offlineNo account and no cloud. The one download is the optional Lensfun lens database, fetched when you ask for it.

Install

Windows

64-bit Windows with WebView2

  1. Download the -setup.exe or .msi from the latest release.
  2. Run it. The installer is not code-signed, so SmartScreen may warn about an unknown publisher; choose More info, then Run anyway.

Windows is the platform PhotoCull is tested on day to day.

Download for Windows

macOS

Apple Silicon, macOS 11 or later

  1. Download the .dmg and move PhotoCull to Applications.
  2. The app is not notarized: right-click it and choose Open, or allow it under System Settings → Privacy & Security → Open Anyway.

Native launch, permissions and editor integration have not been verified on a Mac yet. Read the macOS notes before relying on it.

Download for macOS

To build it yourself, install Node.js 24, Rust and the Tauri prerequisites for your platform, then run:

git clone https://github.com/ficaa1/photocull
cd photocull
npm ci
npm run build
